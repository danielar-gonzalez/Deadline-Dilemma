# Deadline-Dilemma

Este repositorio explora la relación entre el tiempo de entrega y las calificaciones en una clase, con el objetivo de verificar si los estudiantes que entregan más cerca de la fecha límite obtienen calificaciones más bajas. Se utiliza el conjunto de datos "Tiempos1.csv", generado en la materia de Sistemas Digitales de la Universidad de Monterrey durante el semestre de Otoño 2022.

Un cuaderno de Jupyter que contiene:
- Importación de datos y análisis inicial.
- Separación de los datos en conjuntos de entrenamiento y prueba con el cálculo de promedios.
- Entrenamiento de modelos para regresión polinomial, regresión segmentada y KNN.
- Cálculo del RSE para cada modelo y un análisis comparativo.
- Visualización de predicciones en comparación con las calificaciones reales.
